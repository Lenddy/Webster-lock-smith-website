I can see the bug right away. In your navbar, the Services button is calling onProductsClick instead of onServicesClick in two places (sidebar and mobile), and in App.jsx onServicesClick is pointing to serviceRef but the outer wrapper ref is productsRef.
Here's the full fix:

Problem 1 — App.jsx: onServicesClick scrolls to the wrong ref
Right now:
jsonServicesClick={() => scrollTo(serviceRef)}
serviceRef is the inner ref inside Product_services. But the outer div that wraps the whole component uses productsRef. You need to scroll to the outer div first, then let the inner ref handle the rest. Change it to:
jsonServicesClick={() => scrollTo(productsRef)}
The serviceRef is already being used correctly inside onServiceItemClick for the dropdown items.

Problem 2 — Navbar.jsx: Services button calls onProductsClick
In the sidebar (desktop):
js// wrong
onClick={() => {
    onProductsClick();   // ← should be onServicesClick
    toggleMenu("services");
}}
Change to:
jsonClick={() => {
    onServicesClick();
    toggleMenu("services");
}}
Same fix in the mobile sidebar:
js// wrong
onClick={() => {
    onProductsClick();   // ← same bug
    toggleMenu("services");
}}
Change to:
jsonClick={() => {
    onServicesClick();
    toggleMenu("services");
}}

To answer your question — do you need to do the fix twice?
Yes, but only for the Services button click handler — once in the mobile sidebar and once in the desktop sidebar. The top navbar doesn't have a separate Services button so it's fine as-is.

About the later task (services below products on mobile)
You're already set up for it. Since serviceRef is on the services div inside Product_services, calling scrollTo(serviceRef) on mobile will scroll past products directly to services. You just need onServicesClick to actually call that instead of onProductsClick, which is exactly what the fix above does.
